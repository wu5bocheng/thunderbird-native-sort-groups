# Thunderbird 原生组合排序 0.4.0

在原来的「排序」菜单中选择多个字段；**只有勾选原来的「按排序分组」才插入分组标题**。保留原生邮件列表、右侧摘要、阅读窗格和常用编辑命令，不另开页面。

## 安装

Thunderbird →「附加组件和主题」→ 齿轮 →「从文件安装附加组件」，选择上一级目录的 **thunderbird-native-groups-0.4.0.xpi**。

这是旧版 Native Date & Domain Groups 的更新，扩展 ID 不变。若还启用了更早的 Date & Source Groups 独立页面扩展，请禁用那个独立扩展。

## 菜单怎么用

- **发件域名**现在是普通排序字段，与日期、来自、主题等放在同一菜单中；原来的“日期 → 发件域名（实验视图）”选项已移除。
- 已选择的字段标注 **1 ·、2 ·、3 ·、4 · …**，按点击加入的先后决定优先级。
- 点击未选字段会追加为最后一级；再次点击已选字段会移除，后面的编号立即前移。至少保留一个字段；要调整顺序，可以先移除再添加。
- 选择字段后菜单保持打开，方便连续组合。升序 / 降序沿用原来的菜单选项，统一作用于组合。
- **取消「按排序分组」：** 仅按组合字段排序，显示平铺邮件，没有日期或来源标题。
- **勾选「按排序分组」：** 每个已选字段成为一级可折叠分组，默认折叠。
- 扩展工具栏按钮也只切换当前文件夹的「按排序分组」开关，不再是独立视图模式。

例如已经选中 `1 · 日期` 时，点「发件域名」，得到：

```text
✓ 1 · 日期
✓ 2 · 发件域名
✓ 按排序分组
```

想按「来源 → 日期 → 已读 → 星标」分四层：先让发件域名成为第一级，再依次加入日期、已读、星标，最后勾选分组。

字段、选择顺序、升降序和分组开关按文件夹保存，禁用后再启用及重新启动时会读取这些偏好。卡片和表格视图使用同一组合。点击表格列标题遵循常见的单列排序操作，会改用该列单字段；要组合多个字段，请通过排序菜单选择。

原生「按话题」仍使用 Thunderbird 自带的会话模式。选择组合排序字段或勾选「按排序分组」后，回到组合排序 / 分组。

## 支持的字段与排序含义

支持菜单中的 16 个字段：日期、接收时间、星标、接收顺序、优先级、来自、发件域名、收件人、通信者、大小、状态、主题、已读、标签、垃圾邮件状态、附件。可以自由组合，编号没有四级上限。

- 日期 / 接收时间在平铺排序时使用时间值；分组时使用本地时区的今天、昨天、过去一周、过去两周、更早等日期范围。
- 发件域名合并企业子域名，Gmail、Outlook、QQ 等公共邮箱按完整地址区分。来源分类仍按该分类最新邮件的时间排列；降序为最新来源在前，升序反向。
- 大小按字节数排序 / 分组；其他字段按缓存消息头及原生字段显示值分类。标签按同一组标签组合归类。
- 勾选状态根据实际生效的字段和分组模型刷新；未选中时移除 `checked` 属性，而不是写入仍可能显示勾选的 `checked="false"`。原生菜单再次刷新、再次打开时会重新同步编号及勾选。

## 保留的原生功能

点击分组标题，右侧使用 Thunderbird 自带摘要；点击邮件，打开原生正文。箭头与方向键负责展开和折叠，多选按真实邮件身份去重，折叠子组也包含在分组选择内。

已读 / 未读、星标、标签、Spam / 非垃圾邮件、复制、移动、归档、删除委托原生命令执行，沿用账号设置、确认提示及原生事务。删除、移动、归档后的撤销已在隔离测试中验证，常用编辑不需要退出分组。

快速筛选、统一未读 / 保存的搜索沿用原生后端范围。原生未读搜索可能为保持阅读稳定暂时保留刚标记已读的命中；刷新搜索后移除，扩展遵循原生行为。

## 技术边界

界面不再使用“实验视图”名称，但**底层仍需 Thunderbird Experiment API**：原生有主 / 次排序机制，标准 MailExtension 接口只暴露主排序字段，不能完整表达任意多层组合分组。这部分由扩展在原生列表和菜单上补齐，不是新增官方稳定 API，也不修改 Thunderbird 安装文件。安装时需要原生集成扩展的广泛应用权限。

适配并实际测试 **Thunderbird 158.0.1**，清单限制在 158.x。其他扩展读取标准 sortType 时，不一定能取得完整组合；完整优先级保存在本扩展的按文件夹偏好中。

仍未开放：邮件列表拖拽移动，以及关注 / 忽略线程、整线程标记已读、选择线程、下一未读线程和“选择带星标邮件”等特定命令。可使用原生移动菜单；线程专属操作可切回原生话题模式。真实 IMAP 服务器的断线 / 并发组合与其他主版本尚未验证。

本扩展不提供广告去重、后台清理、外部 AI 或邮件上传服务；只有用户主动执行原生编辑命令才会改变邮件位置或标记。

## 验证和源代码

- 6 个纯模型测试：默认折叠、日期 / 来源顺序、任意四级层次、平铺多字段排序、跨文件夹选择去重。
- 隔离 Thunderbird 158.0.1：原生菜单字段追加 / 移除和编号、勾选 / 取消分组、升降序、重开菜单反馈、全部 16 字段组合及 16 层分组。
- 真实鼠标 / 键盘：标题选择、箭头、方向键、Ctrl 多选、摘要内点击打开、实际卡片星标按钮。
- 原生编辑、删除 / 移动 / 归档及撤销；新邮件、快速筛选为一条 / 零条、跨文件夹统一未读、卡片 / 表格、禁用清理和重新启用后的偏好恢复。

使用合成邮件和新建临时配置，没有接入真实邮箱。`preview-native.png` 是原生摘要界面截图，`preview-multilevel.png` 是真实四级分组截图；均为测试数据。

```bash
python3 build.py
node --test tests/model.test.mjs
python3 tests/native_integration.py --binary /absolute/path/to/thunderbird
```

测试使用随机本地 Marionette 端口和独立临时配置，清理自己的测试进程；不连接用户正在使用的 Thunderbird。构建将模型拼入 Experiment 实现，安装包不依赖第三方运行时。

## 语言与开源

使用 Thunderbird 标准 WebExtension i18n 框架，自动跟随应用语言；支持简体中文、繁体中文、英语、德语、法语、西班牙语、日语。原生菜单和窗格继续由 Thunderbird 自身翻译。其他语言回退英语；可通过 `_locales/<locale>/messages.json` 贡献翻译。

以 MPL-2.0 开源，作者 wu5bocheng。源码与问题反馈：https://github.com/wu5bocheng/thunderbird-native-sort-groups 。

英文和官方简体中文语言包均已在独立 Thunderbird 158.0.1 中通过完整集成测试。其余语言已校验资源完整性，尚未逐项人工校对。
